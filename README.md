# Puppy Yoga Bali: frontend redesign demo

A frontend-only redesign of puppiesyogabali.com built with Next.js (App Router, JavaScript), React, GSAP + ScrollTrigger and CSS Modules. There's no backend: booking, gift card and contact buttons link to the current live site, WhatsApp or e-mail.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## Routes

| Route | Content |
|---|---|
| `/` | Hero, intro, rescue partner, locations, photo strip, top FAQs |
| `/sessions` | How a session goes, location picker with booking links, good-to-know |
| `/locations` | Canggu and Ubud venues, arrival notes, maps |
| `/private-puppy-yoga-bali` | Private sessions, gift card preview |
| `/faq` | 11 Q&As in three groups, contact details |

## Images

`public/images/` holds pre-optimised WebP derivatives, and `lib/images.json` lists their sizes and alt text. Next's image optimiser is off (`images.unoptimized`), so these files are served as-is.

They are generated by `npm run images` (Python + Pillow) from the original photos in `docs/source-audit/assets/images`. That folder is local-only and not in the repository. Each image only gets the widths browsers actually request (see `WIDTH_OVERRIDES`). File names include a content hash, so they are served with a one-year immutable cache.

## Content

Facts come from the Phase 1 audit. Disputed figures (adoption and donation totals, review counts, puppy counts, conflicting ticket prices) are left out on purpose. Shared copy and data are in `lib/site.js`.
